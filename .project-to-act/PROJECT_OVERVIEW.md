## 项目目标

- 建立独立于业务应用的团队 Vibe Coding 协作控制面。
- 让不同人员和不同 AI 通过同一任务契约、上下文、修改意图和验收证据保持实现一致。
- 从一个服务监控多个仓库的功能、任务、会话、冲突和 Git 进度。

## 范围

### 包含

- 独立 Web 控制台、只读 API、管理员令牌、项目 allowlist。
- 工具无关 Skill、零依赖 CLI、GitHub 模板和可选插件适配器。
- 本地仓库接入、工作会话与工作量语义、上下文/意图冲突门禁。

### 非目标

- 不生成业务代码，不执行被观察源码，不自动合并或部署。
- v0.1.0 不提供 SaaS 多租户、计费和秒级跨机器在线状态。

## 技术路线与关键约束

- Next.js 16 + TypeScript + Zod；状态事实保存在目标仓库，平台只构建可重建读模型。
- 被观察仓库只能来自版本化项目注册表；Git 命令只读。
- Skill 是权威实现，工具专属插件和规则保持薄适配。

## 数据与安全边界

- 数据分类：仓库元数据、任务事实、会话摘要、Git 路径与提交元数据；不读取源码正文。
- 敏感信息处理：只记录脱敏摘要、证据 ID 和受控位置，不粘贴原始敏感数据。
